# tool_painelava

O `tool_painelava` é um plugin do tipo *Admin tool* para o Moodle que integra a plataforma ao **Painel AVA**, usado no Instituto Federal do Rio Grande do Norte (IFRN), expondo os cursos de um usuário organizados por tipo e um conjunto de endpoints HTTP para matrícula, progresso e preferências.

`tool_painelava` is an *Admin tool* type plugin for Moodle that integrates the platform with the **Painel AVA**, used at the Federal Institute of Rio Grande do Norte (IFRN), exposing a user's courses organized by type and a set of HTTP endpoints for enrolment, progress and preferences.
